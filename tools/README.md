# Tools

- `build_renderer.py`: compile CUDA sources for the current machine.
- `check_env.py`: inspect the Python/CUDA toolchain.
- `evaluate.py`: full-resolution RGB8 PSNR/SSIM/MS-SSIM.
- `Show-TrainingProgress.ps1`: Windows progress display.

The remaining Python modules provide file I/O, color fitting, population validation and image diagnostics for the shared Trainer. Use the repository-root training and codec scripts as the public entry points.
