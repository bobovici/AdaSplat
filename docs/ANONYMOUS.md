# Anonymous review distribution

This source archive contains no Git history, datasets, images, pretrained models,
training outputs or compiled extensions. Original upstream copyright and license
notices must remain intact: third-party attribution is not author attribution for
the submitted paper.

## Recommended publishing procedure

1. Extract this clean archive into a fresh repository. Do not copy an old `.git`
   directory, cached experiments, credentials, screenshots or model files.
2. Upload this source to the repository chosen by the authors. Review commit
   identity and access settings privately. A normal GitHub URL contains an account
   identity and should not be used as an anonymous paper link.
3. Open https://anonymous.4open.science/ and create an anonymous view for that
   repository. Its owner/repository names are anonymized; add personal names,
   account names, email addresses and affiliations as custom terms where needed.
   Preserve code identifiers such as `adasplat`; blindly replacing them breaks code.
4. Prefer a frozen reviewed snapshot/commit rather than changing code during review.
   Set expiry to cover the full review period and follow the conference's current
   artifact policy. No conference-specific identifier is assumed here.
5. Open the generated link while logged out. Inspect README, file contents and
   download ZIP. Search again for personal identifiers and verify that this
   release, not an older repository revision, is served.
6. Put the generated anonymous URL in the submission. Keep a copy of the exact ZIP
   and its SHA-256 privately. If a link cannot be created, use the conference's
   anonymous supplementary-code upload route when permitted.

Service documentation: https://anonymous.4open.science/faq

The archive is prepared for anonymous review; a live anonymous URL is created by
the publishing service after the source repository is uploaded. This document
does not assert that a remote upload or anonymous URL has already been created.
